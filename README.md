## **Chatbot**

This is a chatbot application I built while learning the core concepts of React.js. 
To handle the chatbot's actual reply logic, I integrated a response module provided by [SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev).
##  Features I Added

While the base of this project follows the SuperSimpleDev course, I independently completed several assignments and extended the application with my own custom features:

* **Timestamps:** Implemented dynamic timestamps for when messages are sent.
* **Loading Message:** Added a loading message that displays while the chatbot 'thinks'.
* **More Responses:** Improved the chatbot's response capabilities.



## What I Learned

Through building this and extending the original codebase, I gained a strong understanding of:
* Component structure and reusability
* Managing state and updating the UI dynamically
* Handling user inputs and events

##  Technologies Used

* HTML / CSS
* JavaScript
* React
* SuperSimpleDev Custom chat bot Library
